DayZ-Takaro Integration

Connect your DayZ dedicated server to Takaro for Discord integration, player management, server announcements, and full admin control via the Takaro dashboard.

Download Latest Release View Source

What You Get

  • Server-side script mod (@TakaroIntegration) — runs in DayZ Enforce Script, no client install required
  • Native bridge DLL — keeps a persistent WebSocket open to connect.takaro.io and exposes a local HTTP endpoint to the script mod
  • Discord ↔ in-game chat — messages relay both directions via Takaro's Discord bridge
  • Server announcements — center-screen banners via the announce verb (uses DayZ-Expansion's BAGUETTE notification when present, falls back to popup notifications otherwise)
  • BE RCON pass-through — Takaro's say/kick/ban/players route through BattlEye RCON automatically
  • Custom verbs — tp, give, listplayers, shutdown (with disconnect-drain delay), help
  • Player events — connect / disconnect / chat / death events stream to Takaro with proper platformId (dayz:<BIS-hash>) for cross-game player linking
  • RPT log forwarding — server RPT lines forward to Takaro as log events

Prerequisites

  • DayZ dedicated server (Windows, x64) installed via SteamCMD (app id 223350)
  • Takaro account — sign up at takaro.io or join their Discord
  • Server access (file-system access to the DayZ install directory)

Required Workshop Mods

None mandatory. The integration is purely server-side and does not require players to install anything.

Recommended (Soft Dependencies)

The following workshop mods unlock the full feature set. The integration auto-detects them at compile time and falls back to vanilla DayZ APIs when they're absent.

  • CF (Community Framework) — required by Expansion. Workshop ID 1559212036.
  • DayZ-Expansion-Core — required for the chat-line Discord bridge format and the BAGUETTE banner used by announce. Workshop ID 2572331007.
  • DayZ-Expansion-Bundle (or DayZ-Expansion-Licensed) — needed alongside Core for the chat module's RPC_AddChatMessage.
Without Expansion: Discord messages still display in-game but as NotificationSystem popups in the corner. The announce verb shows per-player popup notifications instead of a center-screen banner. Everything else (BE RCON, events, custom verbs) works unchanged.

Setup: Install the Mod

1. Download the Release

Grab the latest release ZIP from the releases page. The archive contains:

  • @TakaroIntegration/ — the script mod folder, contains Addons/TakaroIntegration.pbo
  • dayz_takaro.dll — the native bridge DLL
  • winmm.dll — the proxy DLL that loads the bridge into DayZServer_x64.exe at startup

2. Drop Files into the Server Directory

Place files alongside DayZServer_x64.exe (typical layout shown for C:\GameServers\dayz\):

C:\GameServers\dayz\
├── DayZServer_x64.exe
├── dayz_takaro.dll              ← bridge DLL
├── winmm.dll                    ← proxy DLL (auto-loads bridge)
├── @TakaroIntegration\
│   └── Addons\
│       └── TakaroIntegration.pbo
├── battleye\
│   └── beserver_x64.cfg         ← BE config (see RCON section)
├── profiles\
│   ├── TakaroIntegration\
│   │   └── config.json          ← created on first start
│   └── BattlEye\
│       └── battleye\
│           └── beserver_x64.cfg ← duplicate of above (see RCON section)
└── serverDZ.cfg
Why winmm.dll? DayZ Server has no native plugin loader, so the bridge uses a winmm proxy: DayZServer_x64.exe imports WINMM, our fake winmm.dll loads first and LoadLibrary's dayz_takaro.dll from the same folder. Don't replace your system winmm.dll — only the one in the server directory.

Setup: Takaro Tokens

1. Register the Server in Takaro

  1. Log into takaro.io
  2. Click Create Game Server
  3. Choose Generic as the type (DayZ uses the generic emitter)
  4. Give the server a name and create it
  5. Open the server's settings page and copy the Identity Token and Registration Token

2. Configure the Bridge

Create profiles\TakaroIntegration\config.json with your tokens:

{
    "IdentityToken": "your-identity-token-here",
    "RegistrationToken": "your-registration-token-here",
    "GameServerId": "MyDayZServer",
    "TakaroApiUrl": "http://localhost:8089",
    "MaxEventsPerBatch": 50,
    "EventBatchIntervalMs": 1000,
    "CommandPollIntervalMs": 2000,
    "RequestTimeoutSeconds": 10,
    "DryRun": 0,
    "LogVerbose": 0
}

The DLL writes a default file on first start if one doesn't exist; copy your tokens in afterwards.

Setup: BattlEye RCON

BE RCON gives Takaro the canonical chat-broadcast (say -1) and admin commands (kick/ban/players). It must be configured in two locations on a fresh DayZ install — this is a DayZ-side quirk, not specific to our mod.

1. Edit battleye\beserver_x64.cfg

Use a real Windows editor (Notepad, VS Code) — the file must use CRLF line endings, not LF:

RConPassword YourSecureRConPassword
RConIP 127.0.0.1
RConPort 2306
RestrictRCon 0
RConIP must be 127.0.0.1: the bridge DLL connects via loopback. 0.0.0.0 can break BE Server's bind on some Windows configurations.

2. Duplicate the cfg into profiles\BattlEye\battleye\

DayZ launches BE Server from the profiles directory at runtime, and BE looks for its config next to the loaded DLL, not at -bepath. Without the duplicate, BE loads but never binds the RCON port — the bridge will then loop on recv error 10054.

copy battleye\beserver_x64.cfg profiles\BattlEye\battleye\beserver_x64.cfg

Whenever you edit the cfg, remember to copy it to both locations.

How to verify: after starting the server, run Get-NetUDPEndpoint -LocalPort 2306 in PowerShell. You should see DayZServer_x64 listening. The bridge log (logs\TakaroLogs\dayz-takaro-*.log) should show [Takaro][RCON] login OK within ~30–45 seconds of boot.

Setup: Launch Parameters

Add the mod to -serverMod and ensure -bepath points at battleye:

DayZServer_x64.exe ^
  -config=serverDZ.cfg ^
  -port=2302 ^
  "-mod=@CF;@DayZ-Expansion-Core;@DayZ-Expansion-Bundle" ^
  "-serverMod=@TakaroIntegration" ^
  -profiles=profiles ^
  -bepath=battleye ^
  -freezecheck ^
  -adminlog ^
  -dologs ^
  -netlog ^
  -cpuCount=12 ^
  -exThreads=11
  • -mod=... — workshop mods (CF, Expansion, etc.) loaded by both clients and server
  • -serverMod=@TakaroIntegration — server-only, no client distribution required
  • -bepath=battleye — required for BE RCON; without it BE never starts

Setup: Verify the Connection

After your first start, check these signs of life:

  1. Server's logs\TakaroLogs\dayz-takaro-*.log shows: 
    [Takaro] DayZ DLL initializing v0.2 (HTTP-bridged)
[Takaro] HTTP listening on 127.0.0.1:8089
[Takaro] WS open to wss://connect.takaro.io/
[Takaro] identified, gameServerId=<your-id>
[Takaro][RCON] login OK
  2. The script log (profiles\script_*.log) shows [Takaro] Bridge attached to MissionServer.OnInit
  3. Takaro dashboard's server page shows Reachable: yes within ~10 seconds
  4. Connect/disconnect events appear in Takaro's events stream when a player joins/leaves

Custom Verbs

These run via Takaro's executeCommand action (the dashboard's command box, or a Takaro module):

say <text>                          - broadcast (BattlEye chat: shows as "(Admin) ...")
help                                - list every command with usage
shutdown                            - kick all + RequestExit (5s drain delay flushes saves)
kick <gameId> [reason]              - disconnect a player by Steam64
ban <gameId> [reason]               - write to BE bans + DayZ ban.txt + kick
unban <gameId>                      - remove from both ban files
tp <gameId> <x> <y> <z>             - teleport to coordinates
give <gameId> <classname> [amount]  - spawn item(s) into the player's inventory
players                             - list every online player (name + gameId)
announce <message>                  - center-screen banner (Expansion BAGUETTE) to all players
announce <title> | <message>        - banner with custom title

Aliases: addBan / removeBan / teleport / giveItem / listPlayers / banner.

Updating

  1. Stop the DayZ server (the running process locks the PBO and DLL)
  2. Replace @TakaroIntegration\Addons\TakaroIntegration.pbo and dayz_takaro.dll with the new release
  3. winmm.dll rarely changes — only replace if the release notes say to
  4. Start the server

Troubleshooting

Bridge doesn't connect (no [Takaro] WS open in log)

  • Check that winmm.dll is in the server folder, not just dayz_takaro.dll alone
  • Verify the tokens in config.json match your Takaro server settings
  • Outbound HTTPS to connect.takaro.io:443 must not be blocked by a firewall

BE RCON login never succeeds (recv error 10054 in log)

  • Confirm beserver_x64.cfg exists in both battleye\ and profiles\BattlEye\battleye\
  • Confirm CRLF line endings (open in Notepad, not nano/vim set to LF)
  • Confirm RConIP 127.0.0.1 and a non-empty RConPassword
  • Run Get-NetUDPEndpoint -LocalPort 2306 — if no entry, BE isn't binding

Discord messages don't show in chat

  • With Expansion loaded: messages render as a chat-line via CCGlobal. If you see nothing, check Takaro's events log for chat-message firing — if it doesn't, the issue is upstream of the mod.
  • Without Expansion: messages render as NotificationSystem popups in the corner, not in the chat scroll.

Other issues

Check logs\TakaroLogs\dayz-takaro-*.log for the bridge's view of what's happening, and profiles\script_*.log for the script mod's. Open an issue on GitHub with both logs attached.
