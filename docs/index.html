DayZ-Takaro Integration

Connect your DayZ server to Takaro for Discord chat, server announcements, and admin control.

Need a Takaro account? Sign up at takaro.io.

Download Latest Release

Required Workshop Mods

  • VPPAdminTools — required for in-game admin tools (map, spectate, ban management, etc.)

Install

  1. Extract the release ZIP into your DayZ server folder (next to DayZServer_x64.exe). You'll have @TakaroIntegration\, dayz_takaro.dll, and winmm.dll.
  2. In Takaro, create a Generic game server and copy its Identity Token and Registration Token.
  3. Create profiles\TakaroIntegration\config.json: 
    {
    "IdentityToken": "your-identity-token",
    "RegistrationToken": "your-registration-token",
    "GameServerId": "MyDayZServer",
    "TakaroApiUrl": "http://localhost:8089"
}
  4. Configure BattlEye RCON in battleye\beserver_x64.cfg with CRLF line endings: 
    RConPassword YourSecurePassword
RConIP 127.0.0.1
RConPort 2306
RestrictRCon 0
    Then copy that same file to profiles\BattlEye\battleye\beserver_x64.cfg (BE reads from the runtime location, not -bepath).
  5. Add to your server launch arguments: 
    -serverMod=@TakaroIntegration -bepath=battleye
    A complete start_server.bat template (place it next to DayZServer_x64.exe): 
    @echo off
cd /d "C:\path\to\your\dayz\server"

start "DayZ Server" "DayZServer_x64.exe" ^
 -config=serverDZ.cfg ^
 -port=2302 ^
 "-mod=@CF;@DayZ-Expansion-Core;@DayZ-Expansion-Bundle;@VPPAdminTools" ^
 "-serverMod=@TakaroIntegration" ^
 -profiles=profiles ^
 -bepath=battleye ^
 -freezecheck ^
 -adminlog ^
 -dologs ^
 -netlog ^
 -cpuCount=12 ^
 -exThreads=11

exit
  6. Start the server. Within 30–60 seconds, Takaro's dashboard should mark the server as reachable.

Commands

Run via Takaro's execute-command action (dashboard command box or any Takaro module):

say <text>                          - broadcast to all players
help                                - list commands
shutdown                            - stop the server (saves first)
kick <gameId> [reason]              - disconnect a player
ban <gameId> [reason]               - ban + kick
unban <gameId>                      - remove ban
tp <gameId> <x> <y> <z>             - teleport
give <gameId> <classname> [amount]  - spawn item
players                             - list online players
announce <message>                  - center-screen banner
announce <title> | <message>        - banner with custom title
